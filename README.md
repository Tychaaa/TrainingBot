# TrainingBot

Telegram-бот-визитка для персонального тренера. Разработан на заказ.

Возможности: информация об услугах и расписании, контакты, запись на
тренировку.

## Стек
Python, aiogram

## Запуск
1. Скопировать `.env.example` в `.env` и указать токен бота
2. `pip install -r requirements.txt`
3. `python trainer_telegram_bot.py`
